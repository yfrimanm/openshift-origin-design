Kernel Samepage Merging (KSM)

The memory request ratio is the percentage of each VM's configured memory that is requested on the cluster (requested ÷ configured, 0–100%).

Configured memory is the VM's memory size. At 25%, a 4 GiB VM requests 1 GiB on the cluster; at 100%, it requests the full configured amount.

This setting sets the cluster-wide default ratio for all VMs. Running VMs apply the change after they reboot.

KSM is a memory-saving deduplication feature designed to fit more VMs into physical memory by sharing the data common between them. It is specifically effective for similar VMs. KSM should only be used with trusted workloads. Turning this feature on enables it for all nodes in the cluster.
