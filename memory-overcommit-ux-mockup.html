Configure reservation ratio New

Configured memory is the memory size the guest OS sees. Reservation is how much of that memory is reserved on the host. The default reservation ratio applies to all VMs in the cluster. 0% reserves nothing; 100% reserves the full configured amount.

Sets the default reservation ratio for VMs in this cluster.

Kernel Samepage Merging (KSM) New

KSM is a memory-saving deduplication feature designed to fit more VMs into physical memory by sharing the data common between them. It is specifically effective for similar VMs. KSM should only be used with trusted workloads. Turning this feature on enables it for all nodes in the cluster.

Deduplicates identical memory pages across VMs to use physical memory more efficiently.
