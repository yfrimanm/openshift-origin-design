Kernel Samepage Merging (KSM)

The memory request ratio is the percentage of each VM's configured memory that is requested on the cluster (requested ÷ configured), on a 0–100% range.

At 25%, a 4 GiB VM requests 1 GiB on the cluster. At 100%, it requests the full configured amount.

This setting is the cluster-wide default for all VMs. Running VMs apply the change after they reboot.

Recommended (75% and above)

Requests most of each VM's configured memory on the cluster.

Use with caution (50% to 74.9%)

Moderate overcommit. Monitor cluster memory pressure.

High overcommit risk (below 50%)

Each VM requests less than half of its configured memory.

This value updates when you click Save. Running VMs keep the previous ratio until they reboot or migrate. New VMs use the saved ratio right away, unless they have a specific ratio set by the VM owner.

KSM is a memory-saving deduplication feature designed to fit more VMs into physical memory by sharing the data common between them. It is specifically effective for similar VMs. KSM should only be used with trusted workloads. Turning this feature on enables it for all nodes in the cluster.
