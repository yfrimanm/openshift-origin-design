CNV-82030 — Bulk VM delete confirmation

PatternFly 6 mockup · Type VM count to confirm · Expandable affected-VM list · CNV-82030

Problem summary

Customer on OCP 4.19 right-clicked a project in the VM tree and chose Delete, believing they were deleting one VM. ~100 VMs were removed. The bulk confirmation dialog title/body is too similar to single-VM delete.
Root UX failure: Scope is ambiguous. Title Delete 3 Virtual machines? reads like a count of selected rows, not “every VM in this project.”

Current — bulk delete today

ConfirmMultipleVMActionsModal

Delete 100 Virtual machines?

Are you sure you want to delete ?
Issues: Same modal component as multi-select delete. No project context. No type-to-confirm. Popover link is easy to miss. Title differs from single VM by count only.

Reference — single VM delete

DeleteVMModal

Delete Virtual machine?

Are you sure you want to delete web-server-01 in namespace production-vms?

Associated disks, snapshots, and secrets may also be removed.

Customer confusion: bulk title Delete N Virtual machines? feels like a variant of this dialog, not a destructive project-wide action.

Proposed — project / tree-view bulk delete CNV-82030 v2

Type VM count to confirm · when isTreeViewAction === true

Delete all Virtual machines in project?

You are about to permanently delete all 100 Virtual machines in project production-vms. This action cannot be undone.

Bulk deletion
This deletes every VM in the project, not just the VM you clicked. Running VMs must be stopped first.

Affected Virtual machines (100)

    Enter the number of Virtual machines shown above to confirm deletion.

    Delete button enabled only when the typed value exactly matches the VM count (digits only, e.g. 100). Click Show all 100 Virtual machines in the list to expand the full scrollable preview inline.
    Rejected v1: Checkbox ack was considered too easy to click without reading. Table multi-select (small N) may still use lighter confirmation; tree/project bulk delete always uses type-to-confirm.
