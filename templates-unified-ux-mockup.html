UX decisions
  • Type scope (All / OpenShift / VM) lives in the toolbar — not inside Filter.
  • Category merges Workload profile + Application category so rows stay populated.
  • Filter uses facet labels (Provider, OS) with no “Shared” wrapper; type sections disclose by scope.
  • Manage columns optionally shows separate Workload profile / Application category with em dash (—) for N/A cells.
Create VM → Template
  • Default (both types checked): mixed card grid; sidebar shows Type + Architecture only — type-specific filters hidden.
  • OpenShift only: reveals OpenShift templates only (Selection mode, Provider, OS).
  • VM templates only: reveals VM templates only (category radios).
  • Toggle the Type checkboxes in the sidebar to compare all three states.
